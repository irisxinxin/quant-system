## 四、roll 的真相：credit 成功 / debit 失血

**成功案例 LITE**（8/12 原话）：sell put $850 收 $5,520 → roll 5 次分别再收 1705/654/405/110/even → 累计 $8,394 → $3,500 买回 → **净赚 $4,894（58%）。五次全 credit。**

**失败案例 SOXL**：三张合成多头（220/210/170）一路 roll down，7/10 付 $2,913、8/27 付 $12,632，**累计实付 debit ≥$15,630，至今未了结**。SOXL 从 6/4 的 $190 跌到 7/31 跌破 $120（-37%）。

→ **判据：roll 时收钱（credit）说明市场还给时间价值；付钱（debit）说明在为已发生亏损买单，且往往要付第二次第三次。**
